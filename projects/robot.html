LLM × ROBOTICS · PROJECT NOTE

让一句话，
变成一次真实动作。

机械臂辅助教学项目：把自然语言任务拆成可理解、可编排、可确认的动作，让第一次接触机械臂的人也能看懂发生了什么。

LANGUAGE → ACTION

THE TRANSLATION

不是让模型“说得像”，
而是让动作真的发生。

01自然语言

“把红色方块放到右侧。”

02任务编排

通过 Blockly 将意图拆成可检查的步骤。

03视觉定位

识别目标、标定坐标，并给出执行前反馈。

04受控执行

动作完成后返回结果，必要时由人确认。

PROCESS MATERIALS
